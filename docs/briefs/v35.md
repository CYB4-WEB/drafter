## What the user asked for (agreed decisions)
1. **Remove flashcards completely** (Make card, Review, card decks, SRS, review reminders, card data on disk). The focus
   timer and study stats (minus card stats) stay in Study.
2. **AI practice questions** replace them: pick a source (lasso selection image, some pages, or a whole file) + free-text
   instructions ("10 hard MCQ in Arabic about chapter 2") → Gemini builds a quiz. Types: multiple choice, true/false,
   short answer, essay. MCQ/TF graded locally; short/essay graded by Gemini (score + feedback). Wrong answers explained.
   Quizzes are saved and can be retaken / deleted.
3. **Select → AI**: in the ink editor (notes, whiteboard, PDF, slides all use it) the lasso SelectionBar gets an **AI**
   button (replacing Flashcard). The selection image goes to Gemini. A **chat panel** opens at the end side (right in
   LTR, left in Arabic — i.e. `end`), closable and reopenable; on narrow widths (phone / split pane) it is a bottom
   sheet. Quick chips: Explain · Answer · Solve step by step · Translate · Make questions; or free text. Follow-ups
   keep the context.
4. **Context escalation**: Gemini may call `request_pages(from, to, reason)` or `request_full_file(reason)`. The app
   shows a permission dialog ("AI wants pages 3–5 of Lecture.pdf because …") → Allow these pages / Allow whole file /
   Deny, with an "Always allow for this file" checkbox (remembered per file). Only what was allowed is sent (page text
   + page images, capped), then the answer continues automatically.
5. **Chats are saved with the file** (reopening the AI panel on that file shows the previous chat; "New chat" clears).
6. **API key**: each user pastes their own key in Settings → AI. Stored only in app-private prefs (`AiPrefs`).
   NEVER put any key in code, resources, docs, logs or tests. One-time privacy notice before the first request
   (free tier: Google may use prompts/images to improve its products; only what you select/allow is sent).

  `MainActivity` to `com.daftar.app.study.NewQuizScreen()` / `QuizScreen(id)`. `Screen.Review` is gone.

## Contracts between agents
**ai-agent provides** (package `com.daftar.app.ai`):
```kotlin
/** What the AI (chat or quiz) can read from a file. Works for PDF, Daftar notes/whiteboards, PPTX/PPT slides, DOCX/DOC,
 *  TXT/MD/RTF…, images, OneNote. Text-only formats are split into ~3000-char "pages". */
object FileContext {
    suspend fun pageCount(file: File): Int
    /** 0-based inclusive range, clamped. Images only when [images] and the format is visual (PDF / note / slides / image);
     *  each image ≤ 1600 px long side. Caller recycles bitmaps. */
    suspend fun pages(file: File, from: Int, to: Int, images: Boolean = true): List<PageContent>
    /** Builds Gemini parts for those pages (text + images), respecting caps (max 20 images, ~120k chars). */
    suspend fun parts(file: File, from: Int, to: Int): List<Gemini.Part>
}
data class PageContent(val index: Int, val text: String, val image: android.graphics.Bitmap?)
```
**FileContext is ai-agent's FIRST deliverable** (quiz-agent needs it) — write it first, compile, note it in your log.

**quiz-agent provides** (package `com.daftar.app.study`):
```kotlin
object QuizRequests {
    /** Prefills the New-quiz screen; the caller then does pane.push(Screen.NewQuiz). */
    fun prepare(file: File?, pages: IntRange?, image: android.graphics.Bitmap?, instructions: String = "")
}
@Composable fun NewQuizScreen()
@Composable fun QuizScreen(id: String)
```
ai-agent's chat "Make questions" chip calls `QuizRequests.prepare(file, page..page, selectionImage)` then
`pane.push(Screen.NewQuiz)` (`LocalPaneNav.current` / `com.daftar.app.ui.pane`). Until quiz-agent has written it you
may get a compile error there — that's expected; check the log of the other agent before assuming a mismatch.

**ai-agent also provides for the lead** (who wires it into `ink/InkEditorImpl.kt` and `ui/Screens.kt`):
```kotlin
@Composable fun rememberAiSession(file: File): AiSession     // one per open file; loads the saved chat lazily
class AiSession {
    val open: Boolean                                         // Compose state: panel visible
    fun startFromSelection(image: Bitmap, page: Int, recognizedText: String?)  // opens panel with the image attached
    fun show(); fun close()
}
@Composable fun AiPanel(session: AiSession, modifier: Modifier)   // the side panel content (width set by caller, ~380dp)
@Composable fun AiSheetHost(session: AiSession)                   // bottom-sheet variant for narrow widths
@Composable fun AiSettingsSection()                              // Settings → AI card
```
Lead decides wide vs narrow (`LocalWidthClass.current == WidthClass.Expanded` → side panel, else sheet).

## Quality notes
- No new dependencies. kotlinx-serialization-json, coroutines, pdfbox-android, Compose Material3 are available.
- Network & Gemini calls off the main thread (Gemini.generate already is); cancellable; show progress; never freeze UI.
- Memory: recycle bitmaps you create; sample page renders; don't keep page bitmaps in chat history in memory longer
  than needed (persist the selection image as a small JPEG next to the chat JSON, not in RAM for every message).
- Markdown in answers: render **bold**, headings, bullet/numbered lists, `code`, code blocks; leave LaTeX as plain
  text but make `$…$` readable (strip the dollars). Answers must be selectable/copyable; "Copy" per message.
- Respond in the user's language: system prompt tells Gemini to answer in the language of the user's request (Arabic
  or English), with RTL rendering handled by Compose.
- Arabic + English strings for every user-visible text. Design per DESIGN.md (flat, 1dp borders, 16dp cards).
